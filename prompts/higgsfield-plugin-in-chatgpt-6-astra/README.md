# Higgsfield Plugin in ChatGPT 6 Astra

## Add Higgsfield to ChatGPT

> You need an active Higgsfield subscription. No API key is required.

1. Open [Higgsfield in ChatGPT](https://higgsfield.ai/s/gpt-6-astra-ig-sayed.developer-lwKUde).
2. Go to **Settings** > **Plugins**.
3. Search for **Higgsfield**.
4. Select **Add**.
5. Sign in to your Higgsfield account and authorize the connection.
6. Start a new chat and paste the prompt below.

## Prompt

```text
@Higgsfield Turn the cat pictures I uploaded into a playable video game. Use the Higgsfield MCP to generate the cat assets. Create the desktop game where I can control with the arrow keys. In addition, I would love the cat to walk around searching for treats and tracking score and avoid obstacles like moving cleaning robot.
```
